# 🌸 Elyon Perfumaria

## 📌 Sobre o projeto

O **Elyon Perfumaria** é um projeto acadêmico desenvolvido como parte das atividades do curso técnico, com o objetivo de criar um sistema web para uma perfumaria.

O projeto busca aplicar conhecimentos de desenvolvimento web, organização de código, integração com banco de dados e construção de interfaces, proporcionando uma experiência simples e intuitiva aos usuários.

## 🛠️ Tecnologias utilizadas

- **PHP** – Desenvolvimento da aplicação e funcionalidades do sistema.
- **HTML5** – Estruturação das páginas.
- **CSS3** – Estilização e responsividade.
- **JavaScript** – Interatividade das páginas.
- **MariaDB** – Gerenciamento do banco de dados.
- **XAMPP** – Ambiente de desenvolvimento local.

## 📂 Estrutura do projeto

```text
elyon/
```

## ⚙️ Como executar o projeto

### 1. Pré-requisitos

- XAMPP instalado.
- PHP.
- MariaDB.

### 2. Clonar o repositório

```bash
git clone URL_DO_REPOSITORIO
```

### 3. Configurar o projeto

Mova a pasta do projeto para o diretório `htdocs` do XAMPP.

```text
C:/xampp/htdocs/elyon/
```

### 4. Configurar o banco de dados

1. Inicie o Apache e o MySQL pelo XAMPP.
2. Acesse o phpMyAdmin.
3. Crie o banco de dados `PERFUMARIA3k`.
4. Importe o arquivo SQL do projeto, caso disponível.
5. Verifique as configurações de conexão com o banco de dados.

### 5. Executar a aplicação

Acesse pelo navegador:

```text
http://localhost/elyon/
```
